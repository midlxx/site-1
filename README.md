# Это мой первый тестовый проект
Суть данного проекта - система тех. поддержки
Вы регистрируете аккаунт пользователя, пишете сообщение и у вас создается чат-тикет, в котором вы будете переписываться с администратором.
В свою очередь администратор вводит свой логин-пароль и попадает в админ-панель, и выбирает чат. Далее отвечает вам.
